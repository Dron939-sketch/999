# Библиотека сцен-метафор (банк образов завода)

У эталона сцена — визуальная метафора фразы, мир меняется каждые 2 секунды.
Этот каталог — готовые образы: пропы лежат в `examples/assets/props/`,
сниппет вставляется в `.anim`. Подбирай метафору под СМЫСЛ реплики.

| Метафора | Когда использовать (тип фразы) | Ассеты / приём |
|---|---|---|
| **Толпа клонов** | «все живут одинаково», «по инструкции», конформизм | 4–6 импортов одного рига в ряд, позы calm; герой в центре ломает строй жестом |
| **Из-за горизонта** | пробуждение, рождение мысли, «ты не замечал» | void.svg; фигура стартует y>1.0 и `moves-to` вверх |
| **Нити марионетки** | «кто тобой управляет», внешний контроль | `puppet-strings.svg` сверху, layer выше персонажа; медленно опускается |
| **Гигантская рука** | давление, власть, «система решает» | `giant-hand.svg` нависает сверху, лёгкое покачивание `rotates` |
| **Клетка-прутья** | «норма — тюрьма», рамки, запреты | `cage-bars.svg` опускается сверху (`moves-to` по y) на героя |
| **Дверь в пустоте** | «выход есть», выбор, шанс | `door-void.svg` в void; герой смотрит, идёт/не идёт |
| **Кабель/штекер** | перепрошивка, подключение, «тебе залили код» | `cable.svg` тянется к затылку; hand_fist хватает |
| **Пьедестал** | эго, кумиры, «стань лучшей версией» (ирония) | `pedestal.svg`; герой карабкается или стоит на нём крошечный |
| **Черепа под ногами** | цена бездумности, «до тебя таких были тысячи» | `skulls.svg` полосой по низу кадра |
| **Красная нить** | зависимость, привязанность (ЕДИНСТВЕННОЕ красное!) | `red-thread.svg` через кадр; spot-color её сохранит |
| **Красная петля** | долги, обязательства, «сам надел» | `red-noose.svg` над героем, опускается |
| **Телевизор** | пропаганда, гипноз ящика, чужие мысли | `tv.svg` + свет из экрана; герой заворожён |
| **Шестерни в голове** | мышление, механизм привычки | `gear.svg` (есть) над головой, вращение |
| **ЭКГ-линия** | «пока ты жив», пульс времени | `ekg.svg` едет через кадр |
| **Титр-карточка** | название, удар текстом, цифра | `tools/title_card.py "ТЕКСТ" -o card.svg` → сет |
| **Инверсия** | шок-момент, «мир перевернулся» | `transition invert 0.4s` |
| **ТВ-шум** | слом реальности, глитч системы | `transition static 0.5s` |
| **Толпа-в-одну-сторону** | «все идут туда — а ты?» | клоны `enters left` → `exits right`, герой стоит |

## Масштаб пропов
Проп рендерится в «родном» размере SVG относительно кадра — если мелкий,
добавь после place: `<prop> scales 2.2` (мгновенно) или с анимацией
`... over 1s`. Нитям марионетки нужен ~2.2, клетке ~1.6.

## Правила
1. Одна фраза — одна метафора. Не громоздить.
2. Красное — только ОДНО в кадре и только по делу (кровь/нить/петля).
3. Метафора живёт 2–4 секунды и уходит; не висит фоном.
4. Пропы поверх героя — `place <prop> at (...) layer 10`.
