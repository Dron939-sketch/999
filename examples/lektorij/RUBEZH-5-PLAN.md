# Рубеж 5 — полное приближение к эталону (по разбору 3 серий)

План выстроен по разбору 3 эпизодов Mr. Freeman. Ритм эталона: медиана плана
**1.2–1.3с**, куча флэш-кадров 0.04–0.08с. Исполняю автономно.

## A. Приёмы отрисовки/цвета (движок)
- [x] **Spot-color красный** — красное выживает в mono-пассе как кровь-акцент,
      остальное в ч/б. Фирменный шок-приём. (apply_monochrome)
- [x] **on-twos** — анимация «на двойках-тройках» (config on-twos: N).
- [x] **Падающие частицы (снег/пепел)** — config snow: N.
- [x] **Инверсия кадра** — transition invert (белое на чёрном, панч).
- [x] **ТВ-шумовая склейка** — transition static.
- [ ] **Радиальные лучи за сверхкрупом** — эмфаза (нужен рендер пропа-оверлея).
- [ ] **Титры-карточки** — жирный белый текст на чёрном (нужен рендер текста/SVG).

## B. Баг движка (блокер декора)
- [ ] **Пропы из `let ... at` не рендерятся** (даже с `shows`). Блокирует
      кровь-брызги, ЭКГ, лучи как отдельные пропы. Чинить в prop/let-инстансинге.
      Обход: красное/лучи можно вносить через СЕТ или cel персонажа (рендерятся).

## C. Монтаж/сценарий
- [ ] Ускорить нарезку интро под ритм эталона (медиана ~1.3с).
- [ ] Красный акцент на финальном панче (через сет/cel).
- [ ] Банк образов эталона в сценарии (толпа клонов, пьедестал, из пола, ЭКГ).

## D. Мотивы-образы (банк для сценариев, из 3 серий)
Черепа под ногами; пьедестал с флагом; связан верёвками; бритва с красным;
толпа клонов в ряд; выныривает из пола/лужи; звёздная крошка; радиальные лучи;
старый ТВ в рамке; титры «ИНОЙ/9 ОКТЯБРЯ/URL».
