# Монтажная карта эталона — Mr. Freeman (разбор по видео)

Замеры по двум эпизодам (ffmpeg scene-detect + покадровый просмотр). Это
ориентир для сценариев завода: ритм, приёмы, мотивы оригинала.

## Ритм монтажа

| Метрика | part 00 (2:58) | эпизод-3 (3:40) |
|---|---|---|
| Планов | 79 | ~40+ |
| Медиана плана | **1.28с** | 3.2с (много «говорящей головы») |
| Средняя | 2.25с | — |
| Планов < 1с | 28 | — |
| Самый короткий | **0.04с** (1 кадр!) | 0.08с |

Вывод: канонический ритм — **быстрый, медиана ~1.3с**, с обилием флэш-кадров
0.04–0.08с. Наши ≤3.5с — верхняя граница; ядро монолога режем чаще.

## Приёмы (что делает оригинал)

1. **Флэш-вставки 0.04–0.08с** — одиночный кадр-удар с гротескной мордой между
   планами. Реализовано: позы `flash_*` (td=0, мгновенный снап) + `wait 0.08s`.
2. **ТВ-шумовая склейка** — экран вспыхивает белым шумом, следующая сцена
   впечатывается. Реализовано: `transition static <dur>` (движок).
3. **Инверсия кадра** — белая фигура на чёрном фоне как удар/акцент. (TODO:
   движковый флаг инверсии кадра.)
4. **Пустота/изоляция** — сверхширокий план, крошечная фигура в сером воздухе,
   много негативного пространства. Применять в сценах-«войдах».
5. **Эмоция = смена рисунка** — маска целиком меняется (зубы/шок/x-глаза).
   Реализовано: hero-cels.
6. **ЭКГ/волна** — линия пульса через экран как графический мотив. (идея для
   вставок «прошивка работает».)

## Мотивы-образы оригинала (банк идей для сценариев)

Куча черепов под ногами; фигура на пьедестале-колонне; толпа клонов в ряд;
фигура тонет/выныривает из чёрной лужи; гигантское перо; телефон с сердечком;
камера-танк; сверхкруп маски на чёрном.
