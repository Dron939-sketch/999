# ОТК завода: реестр дефектов. Что нашли, что чинится, что ещё нет.

Список ведётся, потому что одна и та же болезнь возвращалась трижды: дефект
находила СТУДИЯ ГЛАЗАМИ на готовом видео, а завод его не видел. Правило: у
каждого пункта либо стоит гейт, который ловит его ДО рендера, либо честно
написано, что гейта нет.

## Закрыто гейтом

| дефект | гейт | как ловится |
|---|---|---|
| развороты «прыгают», профиль-доска | `tools/turnaround.py` | шесть условий приёмки замером кадра |
| **смена лица стирает жест тела** | `studio.lint_mimika` (hard) | мимическая поза как `pose` после позы с телом |
| рука забыта в воздухе | `studio.lint_arms` | жест держится слоями дольше 6с без полной позы |
| **фигура стоит столбом** | `studio.lint_dinamika` | смены СИЛУЭТА в минуту, разных силуэтов, доля дефолтной стойки |
| опечатка в имени позы | `studio.lint_imena_poz` (hard) | движок молча ставит дефолт — гейт сверяет имена с ригом |
| надетые очки пропадают | `studio.lint_nosimoe` (hard) | полная поза без `_ochki` гасит кость; срыв через проп разрешён |
| **предмет заявлен и не стреляет** | `studio.lint_chehov` (hard) | проп объявлен и ни разу не действует |
| гротеск идёт очередью | `studio.lint_grotesk` | четыре экстремума лица без спокойного кадра |
| сквозная мысль и конфликт не заявлены | `tools/script_lint.py` | строки `СКВОЗНАЯ:`/`КОНФЛИКТ:` в шапке VO |
| **крыса бежит задом** | `studio.lint_propy` | `facing left` у пропа; гейт кричит только на предметы с передом |
| крепления рук и ног вне силуэта | `tools/sockets.py` | 480 креплений, геометрия по контуру |
| кадрирование планов «на глаз» | `tools/karta.py` | карта фигуры в долях кадра |
| длительности реплик выдуманы | `prep_lipsync` растяжка | паузы блока катов множатся на реальную длину речи |
| звук стоит по плановому монтажу | `sfx.py --times-json` | кии переводятся по опорам из `animdsl timing` |
| ударения не размечены | `script_lint` + U+0301 | знак снимается перед сверкой со списками слов |
| надписи вылезают за кадр | `studio.lint_location` | замер по тексту сета |
| реплика озвучена, но никто её не говорит | `studio.lint_sync` | сверка карты блоков с VO-таблицей |

## Правило ОТК

Дефект, найденный студией глазами, закрывается не правкой сценария, а
ГЕЙТОМ. Правка чинит один ролик, гейт чинит все — включая те, что ещё не
написаны. Пока гейта нет, дефект живёт в этой таблице и не считается
закрытым.
