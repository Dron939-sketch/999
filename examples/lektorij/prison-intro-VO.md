# «Тюрьма ума» — продающее интро курса «Перепрошивка». Сценарий озвучки v2.

Видео: `prison-intro.anim` (2 сцены: клетка ~33 с + титры ~6.5 с, немое).
Голос — Fish (голос Фреди). **Сценарий выстроен по `SCRIPT-FREEMAN.md`**
(формула §5, чек-лист §6): хук-подколка с назначением роли → триада-пулемёт →
разворот на зрителя + псевдосомнение → взлёт (возврат достоинства) →
жало-CTA с подколкой. Двусмысленность «сидеть» (быт/тюрьма) — сквозная.
Задача: зритель захотел пройти курс «Перепрошивка»
(https://meysternlp.ru/blog/lektorij/pereproshivka/ — 10 лекций, бесплатно).
Синхрон: `//lip 1..5` в сцене → завод кладёт голос по конструкции, рот — по
амплитуде mp3 (prep_lipsync). Таймкоды ориентировочные.
