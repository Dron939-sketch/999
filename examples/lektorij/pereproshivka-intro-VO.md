## Дорожка звуков (SFX) — первые 7 секунд решают

Тайм-коды сняты с `animdsl timing` по сценарию, а не проставлены на слух.
Прежние стояли по монтажу вдвое более короткому: перелист «на Лекцию первую»
звучал на четырнадцатой секунде до самой книги, а закольцовывающая капля — за
двадцать секунд до финала. Дальше их правит завод: `tools/sfx.py --times-json`
переводит кии с планового монтажа на фактический по началам реплик.

| Тайм | Звук | Зачем |
|------|------|-------|
| 0:00.0 | Гулкая тишина камеры (room tone) + **капля воды** (одиночная, с эхом) | мгновенная атмосфера |
| 0:01.6 | Вторая капля, тише | ритм тревоги |
| 0:02.3 | Скрип нар (лёгкий) | Фримен шевельнулся — внимание на него |
| 0:19.5 | **Лязг** (металл, приглушённо) | акцент на развороте к стене |
| 0:26.6 | Шаги по бетону ×2 | шаг в упор, сокращение дистанции |
| 0:32.6 | Переворот страницы (плотная бумага) | склейка на книгу |
| 0:39.9 | Второй перелист | на «Лекция первая» |
| 0:46.6 | Низкий гул + **тиканье шестерёнок** (нарастает) | картинка оживает |
| 1:04.7 | Всё резко глохнет, остаётся room tone | финальный взгляд в упор |
| 1:14.0 | Одна капля (как в начале) | закольцовка |

## Липсинк

Когда mp3 готов:
```
python3 tools/lipsync.py intro.mp3 --entity freeman -o lipsync.anim.inc
```
— скрипт снимет огибающую громкости и выдаст точную дорожку ртов
(`pose "talk"/"gab"/"idle"`), которой можно заменить блоки `speaks for` в
`.anim` (вставить содержимое файла на место реплик). Требуется ffmpeg/ffprobe.

## Сборка

```
cargo run --release -- render examples/lektorij/pereproshivka-intro.anim -o intro-video.mp4
tools/compose_video.sh intro-video.mp4 intro-voice.mp3 intro-final.mp4
```
SFX подмешиваются в любом редакторе (или вторым ffmpeg-проходом).
