# Библиотека мимики Мистера Фримена (по разбору эталонных листов эмоций)

Справочник «как строить лицо» для каждой эмоции — для всех будущих съёмок.
Выверено по подлинным кадрам сериала и листам 24 эмоций/поз в репозитории.

## Четыре главных принципа

1. **ГЛАЗА — главный носитель эмоции.** Их ФОРМА меняется сильнее всего;
   именно она считывается первой. Рот — вторичен, брови — акцент.
2. **БРОВИ по умолчанию ОТСУТСТВУЮТ.** Появляются ТОЛЬКО в трёх группах:
   гнев (вниз-к-центру), печаль/тревога (внутренние концы вверх «домиком»),
   скепсис/недоверие (одна бровь поднята). В нейтрали, радости, шоке,
   покое — бровей НЕТ.
3. **ТЕЛО И ОСАНКА — ЧАСТЬ ЭМОЦИИ, не только лицо.** Эмоция всегда идёт
   ВСЕМ телом: наклон корпуса, линия действия (line of action), плечи,
   положение рук/головы. Печальное лицо на прямой бодрой осанке — ложь;
   лицо и тело должны говорить ОДНО. Ниже у каждого состояния указана поза
   корпуса — задавать её вместе с лицом.
4. **Экстремум бьёт.** В кульминации (крик, ярость, гротеск) — не полутон,
   а cel-подмена всего лица на hero/flash-рисунок (гигантские глаза,
   рот с зубами/языком) + резкая поза тела.

## Каталог состояний

Формат: **Глаза | Рот | Брови | Голова | наши part'ы / поза**

### Нейтраль / покой
- Глаза: большие ровные чёрные овалы, прямой взгляд. `eye_left/right`
- Рот: короткая мягкая линия или лёгкая улыбка. `mouth_closed` / `mouth_smile`
- Брови: НЕТ (`blank`)
- Поза: `idle`, `calm`

### Радость / улыбка
- Глаза: овалы, чуть сузить снизу (приподнять нижнее веко). `eye_left/right`
- Рот: улыбка-дуга с загнутыми уголками-засечками. `mouth_smile`
- Брови: НЕТ
- Голова: лёгкий наклон вбок. Поза: `happy`

### Смех / хохот
- Глаза: зажмур — превращаются в дуги-полумесяцы «^ ^». `eye_arc`
- Рот: широко открыт с зубами. `mouth_teeth` / `mouth_wide`
- Брови: НЕТ
- Голова: запрокинута назад. Поза: `laugh`, `hero_laugh`

### Насмешка / ухмылка / smug
- Глаза: ПРИЩУР — нижняя половина под тяжёлым веком. `eye_squint`
- Рот: кривая асимметричная линия, один угол выше. `mouth_m`
- Брови: одна чуть поднята (лёгкий намёк). `brow` rot +6/−6
- Голова: чуть отклонена, подбородок вверх. Поза: `smug`, `hero_sly`

### Скепсис / недоверие / «да ну?»
- Глаза: один прищур (`eye_squint`), другой обычный овал — асимметрия.
- Рот: ровная линия, слегка поджата. `mouth_m`
- Брови: ОДНА поднята высоко (вопрос), вторая обычная. `brow` асимметрично
- Поза: `doubt`, `hero_skeptic`

### Злость / гнев / ярость
- Глаза: УГЛОВАТЫЕ — верхний край срезан по диагонали к центру (нависли).
  `eye_angry_left/right`
- Рот: сжат в жёсткую линию или оскал с зубами. `mouth_m` → `mouth_teeth`
- Брови: ЕСТЬ, опущены к переносице (внутренние концы вниз) «\ /». `brow`
  rot: left +18, right −18
- Голова: чуть наклон вперёд-вниз (нависает). Поза: `stern` → `angry` →
  `rage`; экстремум — `hero_rage` / `flash_rage`

### Печаль / грусть / уныние
- Глаза: КАПЛЕВИДНЫЕ, обвисшие вниз-наружу (нижние края опущены), большие.
- Рот: перевёрнутая дуга (frown). `mouth_frown`
- Брови: ЕСТЬ, «домиком» — внутренние концы ВВЕРХ, внешние вниз «/ \». `brow`
  rot: left −14, right +14
- Голова: опущена, поникла. Поза: `sad`, `despair`

### Страх / испуг
- Глаза: сузить/сжать или бегающие; зрачки к краю. `eye_squint` или овалы
  смещены
- Рот: маленький сжатый или приоткрыт «o». `mouth_o`
- Брови: приподняты «домиком» (как печаль). `brow`
- Голова: вжата в плечи, отклонена назад. Поза: `scare`

### Шок / изумление / «вот это да»
- Глаза: ГИГАНТСКИЕ круглые, распахнуты, с бликом. `eye_shock`
- Рот: круглый «O». `mouth_o`
- Брови: НЕТ (или высоко-нейтральные)
- Голова: чуть назад. Поза: `hero_wow`, `hero_shock`, `flash_shock`

### Гротеск / безумие (кульминация)
- Глаза: огромные, с бликами-точками, чуть косят.
- Рот: РАСПАХНУТ с острыми зубами и языком (пила «WWWW»). `mouth_teeth`
- Брови: НЕТ (безумие без бровей — пустое) или резко вверх.
- ЦЕЛ-ПОДМЕНА всего лица на кадр. Поза: `grotesque`, `flash_grotesque`

### Задумчивость / размышление
- Глаза: обычные овалы, взгляд ВВЕРХ-ВБОК (зрачки смещены к верху). 
- Рот: ровная линия или чуть поджата. `mouth_closed`
- Брови: НЕТ или одна чуть поднята
- Голова: наклон, рука у подбородка. Поза: `think`

### Усталость / скука
- Глаза: ПОЛУЗАКРЫТЫ (тяжёлые веки,半 овала). `eye_squint`
- Рот: вялая прямая линия. `mouth_closed`
- Брови: НЕТ
- Голова: подпёрта рукой, набок. Поза (добавить при нужде): tired

### Подмигивание
- Глаза: ОДИН закрыт (дуга-полумесяц `eye_arc`), другой — обычный овал.
- Рот: лёгкая улыбка. `mouth_smile`
- Брови: НЕТ
- Поза (добавить): wink

### Медитация / умиротворение
- Глаза: ЗАКРЫТЫ — спокойные дуги «‿ ‿». `eye_arc` (или новый calm-lid)
- Рот: нейтраль/лёгкая улыбка.
- Брови: НЕТ. Голова прямо. Поза (добавить): meditate

## Липсинк (виземы) — форма рта по звуку

Тело/эмоция сохраняются (overlay), меняется только рот:
- Закрытые губы (M/B/P): `mouth_m` / `mouth_closed` — visA
- Широкий (A/AA): `mouth_wide` — visD
- Круглый (O/U): `mouth_o` — visE
- Средний (E/I): `mouth_e` — visC
- Зубы/F/V: `mouth_f` / `mouth_teeth` — visF
- Акцент-виземы (`visC/D/E_acc`) — та же форма шире/резче на ударном слоге.

## Правило перспективы (см. RULES.md)

Чем ближе часть к камере — тем крупнее. На ECU эмоции лицо/глаза
масштабируются заметно больше; жест «в упор» (коготь, палец) — крупнее тела.
